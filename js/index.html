About DRC Advisor

The Deployment Resource Checker (DRC) validates Kubernetes and Infinispan manifests against best practices.

  • QoS Analysis: Detects Burstable/Best-Effort risks.
  • Memory Check: Ensures Xmx/Xms consistency.
  • KCS Alignment: Maps rules to Red Hat solutions.

Example Active DRC Rules

  • HA Risk: Triggers if replicas < 2.
  • Resource Constraints: Detects missing CPU/Memory limits.
  • Encryption: Checks for disabled Data Grid encryption.
  • Monitoring: Validates Prometheus scraping annotations.
  • Storage: Checks for Ephemeral vs Persistent storage risks.
  • Probes: Identifies missing Liveness/Readiness probes.
